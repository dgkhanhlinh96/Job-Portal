# Open Roles – AI & Data Japan

A lightweight, candidate-facing job platform curated by Linh Dang for AI, data, analytics and engineering opportunities in Japan.

## First-release features

- Browse roles or group them by company
- Search by role, company or skill
- Filter by role family, company type, location and Japanese level
- View job details without leaving the page
- Save roles locally in the browser
- Mobile-responsive layout
- Career-resource and recruiter-introduction sections

## Run locally

No installation or build step is required. Open `index.html` directly in a browser, or serve the directory with any static web server.

## Publish with GitHub Pages

In the repository settings, open **Pages**, select **Deploy from a branch**, then choose the `main` branch and `/ (root)` folder.

## Before public launch

- Replace illustrative job data with confirmed current openings.
- Add the correct LINE and booking URLs.
- Connect the interest form to an approved, secure form service.
- Confirm how Robert Half branding, job information and candidate data may be used.

The two uploaded admin dashboards are intentionally excluded from this public repository because they contain internal workflow concepts and example candidate information.
